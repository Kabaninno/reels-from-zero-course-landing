# Reels From Zero — Online Course Landing Page

A modern, conversion-focused landing page for a fictional online course that teaches mobile video shooting and editing. Front-end only demo with made-up data, built for a freelance portfolio.

**Live demo: https://Kabaninno.github.io/reels-from-zero-course-landing/**

## Key features

- Bold off-white, black and lime design with sticker-style badges and a CSS-only phone mockup
- Fully responsive layout, tested down to 360 px
- Accordion course program and FAQ
- Testimonials and three pricing tiers
- Pricing buttons open a modal enrollment form with validation, US phone formatting and a simulated "Thank you!" submit
- Countdown timer for the launch discount that survives page reloads
- Accessible: keyboard navigation, focus trap in the modal, reduced-motion support

## Tech stack

- React 18 + Vite (JavaScript)
- Tailwind CSS 4 (`@tailwindcss/vite`)
- lucide-react icons

## Run locally

```bash
npm install
npm run dev
```

Build for production (output goes to `docs/`, ready for GitHub Pages):

```bash
npm run build
```
